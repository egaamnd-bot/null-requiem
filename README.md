# NULL REQUIEM

A fresh Godot 4 action game prototype. The current playable slice is a top-down cyberpunk combat arena with one Riot Enforcer.

## Controls

- **WASD / Arrow keys:** Move
- **J:** Strike when close and facing the enemy
- **Space:** Dodge with a short invulnerability window
- **Shift:** Parry during the enemy's red attack tell
- **R:** Rewind up to 1.5 seconds, restoring player and enemy positions and health

Run the project from Godot with **F6** for the current main scene or **F5** for the project.
